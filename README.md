# SM-G9250 One UI 1.0 Port (Experimental)

This project is an **experimental research port** of **One UI 1.0 (Android 9)** for the **Samsung Galaxy S6 Edge (SM-G9250)**.

During earlier research on **Floyd 5.1**, I encountered multiple issues on SM-G9250, including **non-functional touch input** and several problems related to **00/P**.
Through kernel and device-specific modifications, I was able to make the **touchscreen functional on SM-G9250** in the `SM-G9250_ONE_UI_V1.0.img` build.

⚠️ **Compatibility Notice**
- This build is **only tested on SM-G9250**
- Compatibility with other S6/S6 Edge variants is **not guaranteed**

⚠️ **Known Issues**
- Although basic touch functionality works on **SM-G9250**,  
  **some hardware features are still not functional**
- This project is **not intended for daily use**
